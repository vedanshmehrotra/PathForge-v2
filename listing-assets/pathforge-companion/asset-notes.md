# Logo and screenshot provenance

Logo generated using the built-in image generation tool, following the imagegen skill. Original raster: 1254 × 1254 pixels, PNG with transparent outer corners. Mechanical PNG size exports at 512, 128, 64 and 32 pixels preserve transparency. The existing website PF monogram and charcoal/off-white/steel-blue palette informed the design. No external brand logos were included.

## Exact generation prompt

Use case: logo-brand. Create ONE finished square app icon for PathForge Companion, a thoughtful coding practice companion. Existing PathForge brand is a compact PF monogram on a charcoal rounded square: an off-white P and a muted steel-blue F. Preserve this recognizable identity while making the monogram professionally balanced, optically centered, bold and readable at 32px. Design: geometric sans-serif PF letters, distinct legible P counter, shared visual rhythm with the F, very slightly forward-leaning strokes suggesting progress, large simple silhouettes and generous negative space. Flat vector-like precision, charcoal #141619 rounded square tile occupying 90% of the square canvas, corners radius about 20% of tile width. P fill #E8EAED, F fill #79A1CB. Extremely restrained fine dark-gray perimeter keyline #34383E. No glow, no gradients, no shadows, no textures, no glass effects, no sparkles, no circuitry, no extra symbols, no robot, no LeetCode or Firefox logos. No wording beyond the PF monogram. Transparent canvas outside the rounded square tile. Single icon centered in a 1024x1024 square output, generous consistent margins. This is a production logo asset, not a presentation sheet, mockup, or grid.

## Screenshots

Screenshots were captured from the packaged Firefox extension in an isolated WebDriver profile. The existing verification runner was instrumented only in memory by `.playwright-cli/capture-listing-assets.cjs`; no extension, website, backend or existing test source was edited. All LeetCode/website content and PathForge responses were controlled fixtures. Native extension DOM, rendering, storage, tabs and scripting APIs were used.

The screenshots show setup, sample Accepted analysis and sample Wrong Answer practice suggestions. The results are demonstration data and should be captioned accordingly in the listing.
