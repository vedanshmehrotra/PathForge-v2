How XP works

XP requires an accepted submission matching your current editor code and an approach PathForge can verify. A problem can change XP once per day (UTC). Drafts, Run/Test and repeated checks never change XP. Failed submissions do not cost XP; you can correct and submit again. A problem already being in the catalog does not prevent XP.
